# 🌍 GlobeTrotter — Empowering Personalized Travel Planning

## Odoo Hackathon

GlobeTrotter is a personalized travel planning platform designed to help users plan, organize, budget, visualize, and share multi-city trips from a single platform.

The project focuses on making travel planning simpler by bringing destinations, activities, itineraries, and trip budgets together in one place.
